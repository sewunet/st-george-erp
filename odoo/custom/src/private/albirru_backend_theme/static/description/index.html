Release Notes

v19.0.1.0.2 LATEST   2 August 2026

  Theme Personalization Policy

  • New setting in Settings → Backend Settings that decides who owns the look of the backend.
  • Each user can personalize is the default and keeps the existing behaviour: the company values act as defaults, and every user may adjust colors, fonts and layout for themselves.
  • Company-wide (locked) applies one look to everyone and removes the theme button from the systray entirely, so a branded backend stays consistent across the organization.
  • The policy is set per company, so in a multi-company database one company can lock its theme while another stays open.

  What Each Role Sees

  • Dark mode stays a personal choice under both policies, since it is an accessibility preference rather than branding. It keeps its own systray toggle, which is never hidden.
  • Administrators keep the full Quick Settings panel while a theme is locked, but every change they make there is saved for the whole company, and the panel says so.
  • The All Settings shortcut inside Quick Settings is now shown to administrators only. It opened a General Settings action that other users are not allowed to reach.

  Safe to Switch Either Way

  • Locking erases nothing: settings a user already personalized are kept and apply again the moment the policy is switched back.
  • The restriction is enforced on the server, not only in the interface, so it cannot be bypassed through the theme settings endpoint.
  • The policy itself can only be changed from General Settings by an administrator; it is not writable through the theme endpoint at all.

  Translations

  • Indonesian translations extended to cover the new policy setting and its messages.
  • Translation template regenerated so the strings are ready for other languages.

  Upgrading: no data migration is needed. Existing installations keep working exactly as before, because the new policy defaults to Each user can personalize. After changing the policy, ask users to reload their browser tab so the systray reflects it.

v19.0.1.0.1   1 August 2026

  Security & Data Integrity

  • Company-wide theme settings now require Administrator rights. Previously any internal user could change them through the settings endpoint.
  • Menu background uploads are verified by file signature and limited to 2 MB.
  • Record rules added for app groups, theme configuration (per company) and bookmarks (private per user).
  • Bookmark names are no longer double-escaped; a migration repairs existing records on upgrade.

  Performance

  • Global search now issues a single debounced server request instead of one per model per keystroke, with stale responses discarded.
  • Menu and search results open through the web client instead of reloading the whole page.
  • The main dark mode stylesheet is only downloaded by users actually in dark mode.
  • The app group list is fetched once and shared between components.

  Per-User Personalization

  • Every user can now set their own colours, fonts, density and layout on top of the company defaults.
  • New Reset to company defaults action discards personal overrides.
  • Quick Settings is available to all users; company-wide options stay administrator-only.
  • Switching the menu position no longer reloads the page.

  Dark Mode

  • Now built on Odoo's native colour scheme, so core modules — charts, the HTML editor, Discuss — follow the theme instead of staying light.
  • No flash of light interface before the first paint.
  • Search panel, dialogs and cards using Odoo's background utilities now follow the dark palette.
  • Properties fields and optional-field labels are readable again.

  Odoo 19 Layout Fixes

  • Kanban: restored the responsive grid for ungrouped views, column background and width, card spacing, and full-width columns on phones.
  • Kanban: corrected the card menu icon alignment and position.
  • Pivot: table styling rewritten for Odoo 19 markup — it previously had no effect at all.
  • Form: field label weight, statusbar button spacing, and Chatter at bottom now working on wide screens.

  Accessibility & Translations

  • Keyboard focus is trapped inside the search dialog and restored to the trigger on close.
  • Visible focus ring on kanban cards for keyboard navigation.
  • ARIA labels on interactive controls across the sidebar, drawer and search.
  • Translation template shipped, with a complete Indonesian translation included.

  Upgrading: this release includes a data migration for bookmark names. Upgrade the module normally (Apps → Albirru Backend Theme → Upgrade). If icons or colours look stale afterwards, force a browser refresh so the regenerated assets are picked up.
