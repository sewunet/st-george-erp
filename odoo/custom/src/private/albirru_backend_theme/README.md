# Albirru Backend Theme for Odoo 19

[![License: LGPL-3](https://img.shields.io/badge/license-LGPL--3-blue.svg)](https://www.gnu.org/licenses/lgpl-3.0.html)

**Free & open-source** modern, professional, and customizable backend theme for
Odoo 19. Maintained by **[Albirru Solutions](https://www.albirru.com/)**.

## Features
- **Dark/Light Mode**: Integrated toggle with persistent preference.
- **Advanced Sidebar**: Collapsible, pinnable, and customizable position (Left/Top).
- **Custom Color Schemes**: Multiple pre-defined schemes and custom color picker.
- **Global Search**: Quickly find menus and records.
- **App Drawer**: Organized App Groups for cleaner navigation.
- **Responsive Design**: Fully optimized for mobile devices.

## Installation
1. Install the module `albirru_backend_theme`.
2. Go to **Settings > Theme Settings** to configure your preferences.
